# Decisiones arquitectonicas (ADR) de Anti-Gravital

> Regla 35 de `CLAUDE.md`.

Un ADR (Architecture Decision Record) registra una decision
arquitectonica importante con su contexto, alternativas consideradas y
consecuencias. Es un documento corto que sirve para entender por que
el proyecto esta como esta y para evitar reabrir debates ya resueltos.

## ADR vs RFC

- Una RFC propone una decision y se vive en debate.
- Un ADR registra una decision ya tomada y estable.

Toda RFC aceptada que represente una decision arquitectonica deja un
ADR como rastro.

## Plantilla

Vease `template.md`. La estructura es: Contexto, Decision,
Consecuencias, Alternativas, Estado.
