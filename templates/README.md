# templates/

Templates de proyecto consumidos por `ag new`. Cada template es un
arbol completo que el binario `ag` copia y renombra al crear un nuevo
proyecto.

## Templates previstos

- `rest`: API REST clasica con auth, datos y observabilidad.
- `realtime`: API con soporte WebSocket y SSE.
- `fullstack`: REST mas SSR ligero con `ag-ui`.
- `mobile-backend`: backend optimizado para clientes Flutter con
  generacion del SDK Dart.

## Estado

Fase 0: vacio. Los templates llegan junto con la CLI a partir de
Fase 2.
